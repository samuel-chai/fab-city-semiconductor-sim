# 晶圓城 FAB CITY

一個可玩的低多邊形半導體製造互動教材。玩家把同一批晶圓依序送進 14 個製程站，管理能源、超純水、製程點數、污染與良率，並在製程偏差事件中做選擇。

## 內容

- 14 站完整流程：矽原料／單晶、晶圓、氧化／薄膜、光刻、蝕刻、摻雜／離子植入、沉積、CMP、金屬互連、多層製程、晶圓測試、切割、封裝、最終測試
- 點擊建築或拖曳晶圓流轉
- 依順序解鎖；多層製程用三輪遊戲循環代表真實工廠的大量重複
- 資源、污染、良率與隨機製程事件
- 裝置本機自動保存進度
- 完整知識庫、自我審核與一手資料來源
- 桌面、平板與手機版面

## 在本機執行

需要 Node.js 22.13 以上。

```bash
npm install
npm run dev
```

打開終端顯示的本機網址即可遊玩。

## 建立靜態網站

```bash
npm run build
```

靜態成品會出現在 `dist/client`，可部署到任何靜態網站服務。

## GitHub Pages

專案已附上 `.github/workflows/deploy-pages.yml`。第一次使用時：

1. 在 GitHub 建立空白 repository，將本專案推送到 `main` 分支。
2. 到 repository 的 **Settings → Pages**，將 **Source** 選為 **GitHub Actions**。
3. 推送後，工作流程會自動建立並發布網站；之後每次更新 `main` 都會重新部署。

設定會自動處理一般 `username.github.io/repository-name/` 專案路徑，不需要手動修改程式。

## 知識邊界

這是入門教學模擬，不是可用來設定真實機台的製程配方。遊戲把數千個實際步驟壓縮成 14 站，並把良率用單一數值表示；真實製程還包含大量清洗、量測、缺陷檢查、統計製程控制與產品特定步驟。

主要核對來源：SUMCO（單晶與晶圓）、ASML（光刻）、Applied Materials（CMP／材料工程）、Intel（封裝與測試）。網站內附直接連結。
